# 功能对照与参考来源

核对日期：2026-11-17。参考的是官网可见说明，未运行或反编译原 Windows 程序；“已实现”指独立实现对应行为，不代表全部内部细节与原软件相同。

| 官网公开能力 | 苇读对应实现 | 验证 / 限制 |
| --- | --- | --- |
| 本地 TXT / EPUB / MOBI | 拖放和批量导入、编码识别、EPUB spine 顺序、MOBI 独立进程解码 | 原创测试夹具通过；MOBI 仅无 DRM；EPUB/MOBI 按纯文本重排，不含插图排版 |
| 隐蔽 mini 阅读器 | 独立无边框小窗、拖动、缩放、置顶、快速隐藏 | 当前 X11 实测 |
| 字体、颜色、文字/背景透明度 | 字体、字号、行距、颜色与三个独立透明度参数 | 设置往返测试和实际窗口检查；透明效果依赖合成器 |
| 自动阅读、滚轮翻页 | 可调间隔自动翻页、滚轮翻页、隐藏时暂停 | GUI 自动化通过 |
| 快捷键绑定 | 默认 Alt+Z / Alt+C / Alt+V，可自定义；额外全局隐藏全部 | X11 真正全局抓键实测；Wayland 使用桌面自定义命令 |
| 沉浸阅读 | F11 全屏模式 | Qt GUI 路径实现；普通/小窗截图检查 |
| 章节与内容搜索 | 章节过滤、正文搜索及跳转 | 中文/emoji 偏移测试通过；网络仅搜索缓存 |
| 进度选择 | 全书进度拖动、断点续读、书签 | SQLite 重启验证；全书百分比按章节等权估算 |
| 阅读配置分享/加载 | 有版本字段、严格验证的 JSON | 往返/非法输入测试；不兼容原软件私有配置码 |
| 书架布局和收藏 | 封面/列表视图、收藏、书名作者过滤 | GUI 测试通过；封面为原创文字排版，不抓取图片 |
| 网络书架 / 阅读 App 同步 | 用户配置的 Legado HTTP 服务、手动双向进度同步 | 本地 HTTP 模拟服务集成测试；真实 Android 设备未验证 |
| 在线章节预加载 | 缓存当前章和下一章，追加更新目录 | 已测试缓存和离线读取；没有整本离线下载按钮 |
| 原格式显示 | 保留正文段落或合并行显示 | 支持纯文本段落，不复刻电子书 CSS / 图片 |
| 进度显示位置 | 顶部 / 底部 / 隐藏 | 设置与 UI 实现 |
| 任意窗口透明工具 | X11 窗口列表选择、设置及恢复透明度 | 对测试自己创建的窗口验证；Wayland 不提供此能力 |
| 窗口位置与尺寸记忆 | 书架/阅读器/小窗分别记忆 | GUI 回归与 X11 实测；Wayland 位置由合成器决定 |
| 程序更新 | 包管理器升级和源码构建 | 未实现原软件的内置在线更新器；不接入其更新服务器 |
| 鱼塘/聊天社区 | 未实现 | 官网日志已说明移除；不属于当前阅读器功能 |

## 0.2.0 增补：微信读书

按用户后续要求接入微信读书官方网页版。该能力是苇读新增功能，不来自对 Fish-book 私有接口的复刻。支持扫码登录入口、官方书架与阅读页、独立 profile、透明阅读条、缩放、独立文字/背景透明度和跨窗口快捷键路由。见 [使用与验证边界](weread.md)。
