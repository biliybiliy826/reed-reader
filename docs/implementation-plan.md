# 执行计划 · 2026-11-17

## 目标
独立实现 Fish-book 公开说明中的主要阅读能力，交付 Linux 原生应用、完整源代码、GPL-3.0-only 许可证、可复现测试和安装入口。

## 非目标
复制原软件代码/品牌/素材；承诺闭源 Windows 程序的像素一致性；内置第三方小说站点；自动修改用户其他窗口；未经指定就发布到远程账号。

## 决策
- Python 3.11+ / PySide6 Essentials，避免 WebEngine 运行时。
- TXT / EPUB 自行规范化；MOBI 使用 GPL-3.0-only 的 mobi 0.4.1。
- SQLite 保存书架、正文缓存、进度、书签；JSON 保存设置，原子写入。
- X11 全局快捷键使用 python-xlib；Wayland 提供 IPC 命令给桌面自定义快捷键。
- 网络书架使用用户配置的 Legado HTTP 服务，显式拉取和推送进度；缓存当前章及下一章。

## 发现并修复的问题

1. Qt 切换窗口 flags 触发 hideEvent，导致大窗口尺寸写入 mini 配置。改为在改变模式前先隐藏并保存旧模式；增加小窗尺寸回归测试。
2. 进度拖到 100% 时字符位置位于正文末尾，造成空白页。改为定位最后一页开头，保持 100% 显示并正确恢复。
3. Qt 同时监听双击和激活信号会重复打开书籍/跳转。统一使用 itemActivated。
4. MOBI 库在异常中可能未返回临时目录，调用者无法清理。将解码放在有资源限制的独立进程里，整个临时根目录由父进程负责清理；增加失败清理测试。
5. 原生快捷键测试最初选择 Ctrl+Alt+F10，受到桌面虚拟终端保留组合影响。改用 Ctrl+Alt+Y 后通过；默认 Alt+V 也单独验证触发。此为测试组合问题，没有把保留键当作应用失败后忽略。

## 剩余边界

- 无 Android 真机：网络协议经本地模拟服务验证，真实阅读 App 版本的互通尚未实测。
- 无 Wayland 会话：提供桌面 IPC 快捷键替代方式，不声称其他窗口控制或位置恢复可用。
- 不支持 DRM；EPUB/MOBI 重排为纯文本，图片/CSS 排版不在本次范围。
- 没有仿制原产品在线升级器和已下线社区；详见功能对照。
- GPL-3.0-only 源码与本地发布包已交付，远程公开仓库需用户指定目的地后发布。
